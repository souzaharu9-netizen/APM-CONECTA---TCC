🖼️ Guia: Adicionar Imagens à Página de Abertura

Instruções passo a passo para adicionar as imagens que você forneceu

1Preparação

Você tem 2 imagens que precisam ser adicionadas ao projeto:

  • classroom.jpg - Imagem de sala de aula (background hero)
  • study.jpg - Imagem de criança estudando (seção sobre)

2Localização da Pasta

As imagens devem ser colocadas em:

apmconecta/public/images/

Estrutura do projeto:

APM-CONECTA---TCC/ ├── apmconecta/ │ ├── public/ │ │ └── images/ ← Coloque as imagens aqui │ ├── src/ │ ├── package.json │ └── vite.config.js └── README.md

3Copiar Imagens

Você pode adicionar as imagens de 3 formas:

Opção A: Usando o Explorador de Arquivos (Recomendado)

  1. Abra o VS Code em apmconecta/public/images/
  2. Arraste e solte os arquivos de imagem na pasta
  3. Pronto! As imagens estarão disponíveis

Opção B: Usando Terminal

# Se tiver os arquivos em outro local cp /caminho/para/classroom.jpg apmconecta/public/images/ cp /caminho/para/study.jpg apmconecta/public/images/ # Verificar se foram copiados corretamente ls -la apmconecta/public/images/

Opção C: Salvando Screenshots

  1. Abra as imagens que você enviou
  2. Clique com botão direito → Salvar imagem como...
  3. Salve em apmconecta/public/images/ com os nomes corretos

4Verificar as Imagens

Após adicionar as imagens, você deve ter:

apmconecta/public/images/ ├── classroom.jpg ├── study.jpg └── README.md

5Testar no Navegador

Inicie o servidor de desenvolvimento:

cd apmconecta npm run dev

Acesse http://localhost:5176/ e veja as imagens sendo exibidas:

  • 🖼️ Classroom.jpg aparecerá no hero section (fundo)
  • 📸 Study.jpg aparecerá na seção "O que é o APM Conecta?"
⚠️ Importante: Os nomes dos arquivos devem ser exatamente:
  • classroom.jpg (minúsculas)
  • study.jpg (minúsculas)
✅ Tudo pronto! Após adicionar as imagens, o site exibirá o design completo com as fotos da página de abertura. O código já foi preparado para receber as imagens automaticamente.

📊 Dimensões Recomendadas

  • classroom.jpg: Mínimo 1200x600px (ideal 1920x1080px ou maior)
  • study.jpg: Mínimo 600x450px (ideal 800x600px ou maior)

Nota: As imagens serão redimensionadas automaticamente pelo CSS, mas quanto maior a qualidade, melhor o resultado final.

❓ Dúvidas Frequentes

P: As imagens não estão aparecendo?

R: Verifique se os nomes estão corretos (classroom.jpg e study.jpg em minúsculas) e se estão na pasta apmconecta/public/images/

P: Qual é a diferença entre JPG e PNG?

R: JPG é melhor para fotos (menor tamanho), PNG é melhor para transparência. Ambos funcionam.

P: Posso usar outras extensões?

R: Sim! WebP (melhor compressão), SVG (escalável), ou qualquer formato de imagem comum.
