# Imagens do Projeto APM Conecta

Adicione as imagens nesta pasta para que sejam exibidas na página de Abertura.

## Arquivos necessários:

### classroom.jpg
- **Localização na página**: Hero section (background)
- **Descrição**: Imagem de sala de aula com professor e alunos
- **Dimensões recomendadas**: 1920x1080px (mínimo 1200x600px)
- **Formato**: JPG ou PNG

### study.jpg
- **Localização na página**: Seção "O que é o APM Conecta?"
- **Descrição**: Imagem de criança/crianças estudando
- **Dimensões recomendadas**: 600x450px (mínimo)
- **Formato**: JPG ou PNG

## Como adicionar as imagens:

1. Coloque os arquivos de imagem nesta pasta (`public/images/`)
2. Os arquivos serão referenciados como `/images/nome-do-arquivo.extensão`

## Referências no código:

- `src/pages/Abertura/Abertura.jsx` - Componente que usa as imagens
- `src/pages/Abertura/Abertura.css` - Estilos das imagens

## Notas:

- As imagens são servidas automaticamente pelo Vite durante desenvolvimento
- Na produção, os arquivos na pasta `public/` são copiados para a raiz do build
- Use formatos otimizados (WebP quando possível) para melhor performance
